# 异环薄荷 · NTE Mint

以《异环》薄荷为参考制作的非官方 Codex 宠物。

![跳跃预览](nte-mint-preview-jump.gif)
![挥手预览](nte-mint-preview-wave.gif)

## 安装

下载仓库 ZIP 并解压，进入 `nte-mint` 文件夹，运行 `安装异环薄荷-NTE-Mint.bat`。

脚本将 `pet.json` 和精灵图复制到当前用户的 `.codex/pets/nte-mint/`；已有同名文件夹会先备份。安装后重新打开 Codex 宠物选择面板，选择“薄荷”。需使用支持本地宠物的客户端。

也可以手动将 `pet.json` 和 `nte-mint-spritesheet.webp` 放到上述目录。

## 文件

- `pet.json`：宠物配置。
- `nte-mint-spritesheet.webp`：动画精灵图。
- `nte-mint-preview-*`：动画预览。
- `nte-mint-contact-sheet.png`：动作总览。
- `install.ps1`、`安装异环薄荷-NTE-Mint.bat`：安装脚本。
- `checksums.sha256`：本目录文件的 SHA256 校验值。
